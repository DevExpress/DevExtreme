DevExtreme components use the [Intl](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl) API to format dates, numbers, and currencies for the current locale. DevExtreme also ships with more than 30 [dictionaries](/Documentation/Guide/Common/Localization_and_Globalization/UI_Text_Localization/#DevExtreme_Dictionaries_Reference) that translate component UI text into different languages.

Use the **Language** drop-down menu below the DataGrid to switch between English, German, and Russian. The DataGrid displays column captions and built-in UI text in the selected language, and formats dates and currency values for the corresponding locale.
<!--split-->

[Load dictionaries](/Documentation/Guide/Common/Localization_and_Globalization/UI_Text_Localization/) and call the [locale(locale)](/Documentation/ApiReference/Common/utils/localization/#localelocale) method at startup to localize your application. To change to another locale, reload the page and call the method with a new value. You can also [add strings to dictionaries](/Documentation/Guide/Common/Localization_and_Globalization/UI_Text_Localization/#Add_Strings_to_a_Dictionary) to translate custom text. This demo uses this approach to translate column captions.

The DataGrid in this demo displays dates in the default format for the selected locale. You can change default date, time, and number formats for all DevExtreme components to ensure a consistent look and feel across your application. To define application-wide formats, configure global format properties in the [GlobalConfig](/Documentation/ApiReference/Common/Object_Structures/GlobalConfig/) object (for example, [dateFormat](/Documentation/ApiReference/Common/Object_Structures/GlobalConfig/#dateFormat)). Formats defined in components take precedence over these settings.

In this demo, UI text and value formats use the same locale. You can also specify another locale for dates, times, and numbers. For example, you can allow users to switch the UI language while preserving date/number formats. To format values in a different locale, specify the [locale](/Documentation/ApiReference/Common/Object_Structures/Format/#locale) field in global format properties or in component format properties. Refer to the following help topic for additional information: [Use Different Locales for Value Formats and UI Text](/Documentation/Guide/Common/Localization_and_Globalization/Value_Formatting/#Use_Different_Locales_for_Value_Formats_and_UI_Text).
