# Журнал расхождений fluent-next

Видимые отличия от legacy-темы Fluent и пробелы в foundation, обнаруженные при миграции на токены.

> **Словарь ролей.** Имена ролей в датированных записях ниже приведены **на момент своей записи**.
> Пакет `262.10.1` (#34916) переименовал оба тира: `surface` → `bg`, `neutral`/`default` и явный
> `rest` убраны, `subdued` → `subtle`, `compound` → `shared`, `deep` → `low`, `accessible` → `contrast`;
> компонентный тир перестроен (`button-outline-color-bg-rest` → `button-color-contained-*`). Живое
> написание — в `scss/_design-system/variables/_ds.scss` и в `tokens.flat.json` пакета; полные ссылки
> вида `ds.$…` / `--dxds-…` в этих доках уже приведены к нему, сокращённые упоминания — нет.

Аудитория: команда дизайн-системы. Контекст темы — в [README.md](README.md).

`escalate` (дыра в foundation, вопрос в команду пакета токенов) / `obsolete` (запись потеряла смысл).

- Проблема: `var(--dxds-…)`, вшитый в `fill`/`stroke` внутри data-uri, **не резолвится** — SVG является независимым документом, кастомные CSS-свойства хоста в него не каскадируются, поэтому он отрисовывается **чёрным**. Проверено эмпирически (data-uri с `<rect fill="var(--x)">` отрисовывается как `rgba(0,0,0,255)`; то же самое с конкретным rgb отрисовывается корректно).
- Найденное влияние: в более ранних волнах были токенизированы `$popup-title-color` / `$button-default-color`, которые diagram вшивал в `toolbox-drag` / `properties-panel-open` → эти иконки отрисовывались **чёрными** в закоммиченной сборке. Аудит скомпилированного CSS (декодировать каждый uri `data:image/svg+xml`, искать `var(--dxds`) выявил ту же регрессию в **list** (`.dx-icon-toggle-delete` через `$list-icon-color`), **timeView** (циферблат + часовая/минутная стрелки через `$clock-digits-color`/`$timeview-inverted-bg`/`$timeview-typography-bg`) и **gantt** (16 иконок тулбара через `$datagrid-columnchooser-item-color`, после прохода по gridBase).
- Применённое исправление (внутри виджетов): цвета иконок в data-uri остаются **конкретными значениями `$base-*`** — diagram: `$diagram-text-color: $base-text-color` (иконки действий + toolbox-drag), `$diagram-properties-panel-icon-color: $base-inverted-text-color`; list: новая `$list-toggle-delete-icon-color: $base-icon-color` (использования `$list-icon-color` в CSS-свойстве `color:` остаются токенизированными); timeView: `$clock-digits-color: $base-text-color`, `$timeview-inverted-bg: $base-inverted-bg`, `$timeview-typography-bg: $base-typography-bg` (все три питают только data-uri циферблата); gantt: см. его проход w5. Возвращает legacy-цвета иконок по режимам.
- Эскалация: чтобы токенизировать это, DS должна поставлять либо конкретные (не-`var`) значения цветов иконок для шага сборки data-uri, либо компоненты должны перейти на инлайновый SVG / `mask-image` + `background-color` (изменение разметки, вне рамок NFR-1). У инлайнового SVG `stroke`/`fill` (например, `.dxdi-spinner`, `.dxdi-warning` в diagram) `var()` ПРИНИМАЮТ и были токенизированы обычным образом.
- **Осторожно с обратной стороной:** маркер `dx-data-uri-static` — это исключение, а не удобный способ «зафиксировать значение». В ревью-раунде 1 под него по ошибке попал `$gantt-accent`, который ни в один data-uri не уходит (см. запись про gantt ниже) — литерал разрывал цепочку токенов без причины. Прежде чем помечать переменную маркером, проверьте её потребителей: она обязана уходить в `<хелпер data-uri>` / `escape()` / замену `currentColor`, а не в обычное CSS-свойство. Инвентарь настоящих потребителей в gantt — только `$gantt-icon-color`.
- **Ревью-раунд 2 (12.08.2026):** решение **5** — приняты legacy-литералы для цветов иконок в data-uri; ни запрос не-`var()` значений, ни переезд на `mask-image` не заказываются, эскалация снимается.
