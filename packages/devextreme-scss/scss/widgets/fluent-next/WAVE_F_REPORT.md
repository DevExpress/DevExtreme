## Верификация (методология, применявшаяся в каждой волне)

1. **Модельный резолв-дифф** собранных бандлов против снапшота до волны: ключи
   (scope§selector§prop) не меняются, каждое сырое отличие резолвится байт-идентично после
   разворачивания var()-графа. Пост-обработчик сборки сливает дублирующиеся селекторы и
   минифицирует — байтовый префикс-дифф невозможен, канонизация: пробел calc-деления,
   `background: transparent`↔`0 0`, ведущий ноль, `transition` без `all`, стоп градиента
   `0`↔`0%`, свёртка `margin: 0 0`, «нулевой calc == 0».
2. **Хэши легаси-бандлов** (generic/material/fluent) до/после — байт-идентичность как факт,
   не предположение.
3. **Живой браузерный смоук** (playground + реальные виджеты): резолв-дифф DOM-слепой —
   дыру достижимости тулбарного оверфлоу-меню поймал только смоук (корни расширены до 4
   поверхностей).
4. **Рантайм-аудит достижимости** (добавлен F12 по живому багу htmlEditor):
   `playground/tier-reachability-audit.html` — галерея виджетов + CSSOM-обход, «каждый
   заматченный элемент видит каждую читаемую переменную»; текущий прогон **3020 проверок / 0 дыр**
   (закрыты: htmlEditor без .dx-texteditor, кнопка DDE без .dx-button, inherit в кастом-пропе).
5. Гейты: jest (67), stylelint (0), `naming:check` (rename-гард + реестры + `--emit --check`).

## F14: боевое крещение — скриншот-фейлы PR #34774

Первый прогон CI по извлечённому тиру уронил ~60 скриншотов. Разбор дал три класса наших ошибок
и по фиксу-предохранителю на каждый:

1. **`!important` в значении переменной.** `$grid-margin-inline-start: ds.$spacing-50 !important`:
   на объявлении кастом-пропа важность управляет каскадом самого пропа и потребителю не передаётся —
   правило проиграло `…td:first-child .dx-menu { margin-left: 0 }` из base, фильтр-меню съехало
   на 5px во всех грид-скриншотах. Фикс: чистое значение + `!important` на правиле-потребителе;
   sync-гейт получил машинный эксклюзив `important` с рецептом в сообщении об ошибке.
2. **Дыры корней у сателлитов.** Adaptive-оверлей dxMenu (без `.dx-menu-base`) и попап
   хедер-фильтра не были корнями тира → их правила читали пустоту. Фикс: menu +=
   `.dx-menu-adaptive-mode`, grid += `.dx-header-filter-menu` (реестр + коллектор + деривация).
3. **Слепота собственных инструментов.** Галерея рантайм-аудита не открывала фильтр-меню,
   хедер-фильтр и adaptive-режим — vacuous pass (дополнена + openers + белый список
   RUNTIME_CONTRACT); все модельные резолв-диффы читали `decl.value` без `decl.important`
   (postcss хранит важность отдельным полем) — потеря была им невидима (компаратор починен).

Валидация: рантайм-аудит **3664 проверки / 0 дыр** со всеми открытыми сателлитами; маржин
фильтр-меню `8px 0 0 5px` == prewave (ровно тот −5px CI-регресс); глобальный счётчик
`!important` в бандле 66 == 66; легаси байт-идентичны; гейты 67/67; lint 0. Урок дуги: аудит
проверяет резолв, модельный дифф — значения, каскад проверяют только скриншоты — слои
дополняют друг друга, и каждый инцидент обязан оставлять после себя машинную защиту.

## F15: второй круг — порталы и межскоупный дубль

F14 закрыла 37 из 61 скриншота. Оставшиеся 24 оказались двумя классами, и оба — про то, где
переменная объявлена, а не какое у неё значение (резолв-дифф prewave→сейчас по-прежнему пуст):

1. **Порталы.** JS создаёт элемент вне корня виджета: превью тащимой колонки уходит в swatch-контейнер,
   клон и плейсхолдер sortable — во вьюпорт, попап AI-ассистента — в обёртку с `.dx-ai-chat
   .dx-aidialog`. Тир их не достигал, и невалидные декларации не откатывались к прежнему значению, а
   исчезали: превью колонки без фона, клон строки без тени, карточка ассистента с чёрной рамкой и
   тёмной вместо зелёной иконкой. Лечение — класс портала становится корнем (grid += 3, sortable += 2).
2. **Межскоупный дубль.** `base/dataGrid` и `base/treeList` рисуют фокус-кольцо кнопки AI-колонки
   одинаковым селектором **без скоупа виджета**. В легаси оба значения — `2px solid`, и победа копии
   treeList безвредна; тир подставил per-widget имена, и внутри DataGrid победитель читает переменную
   с `.dx-treelist` → пусто → кольца нет (7 скриншотов). Лечение — значение для неразскоупленного
   правила обязано жить в общем слое: `$grid-outline-focused` в gridBase.

Защиты: гейт **межскоупных дублей** (`tools/review/reachability.mjs` в `naming:check`, падает с
рецептом; негативная самопроверка на бандле до фикса — падает, после — проходит) и отчёт чтений вне
текста корня как материал для галереи; рантайм-аудит дополнен разметкой порталов — **3762 чтения /
0 дыр**. Итог дуги по инструментам: значение проверяет резолв-дифф, достижимость — рантайм-аудит,
конфликт объявления и каскада — этот гейт, а исход каскада на пикселях — по-прежнему только
скриншоты.

### Проверка F15 в CI пока не состоялась: кэш подменил бандл

Прогон на коммите с исправлениями дал **байт-идентичные** прошлому прогону скриншоты. Причина не в
теме: `devextreme:build` объявляет выводом всю папку `{projectRoot}/artifacts`, включая
`artifacts/css`, которую пишет `devextreme-scss:build`, а inputs у него — только собственные
исходники. При правке только в scss хеш scss-сборки меняется, CSS пересобирается — и следом
cache-hit `devextreme:build` восстанавливает свою копию `artifacts/`, затирая свежий CSS предыдущим.
В артефакте прогона нет ни `.dx-ai-chat` среди корней, ни `--dx-grid-outline-focused`. Разбор и
рецепты — GOTCHAS §23; разово снимается меткой `skip-cache` на PR.
